1. Jelaskan apa yang dimaksud dengan dokumen root ?
Dokumen root adalah lokasi folder dimana file website dari sebuah situs disimpan. Jadi, jika kita membuka sebuah website, root adalah halaman pertama yang dilihat sebelum masuk ke halaman-halaman lainnya.


2. Pada apache web server, apakah dokumen root harus terletak dalam direktori C:\xampp\htdocs ? Jelaskan jawaban anda 
Tidak harus, karena dokumen root dapat di letak kan dimana saja tidak harus di C:\xampp\htdoc lalu Kembali lagi pada definisi dokumen root yang digunakan oleh apache untuk menyimpan file web yang dapat diakses oleh pengguna. Sedangkan direktori dapat diatur melalu konfigurasi apache. Sehingga dokumen root ini dapat diletalkan diamana saja.


3. Jelaskan apa yang dimaksud dengan perintah git : init, clone, remote, add, commit, push dan checkout
- Perintah git init digunakan untuk membuat repositori git baru, jika kita mengetik git init, git akan membuat folder tersembunyi bernama .git di dalam folder web2. (.git ini berfungsi untuk menyimpan semua data untuk mengelola repositori Git)
- Perintah git clone ini untuk meyalin repositori Git yang sudah ada, jadi kita bisa melakukan apapun seperti mengirim tugas, dll di repositori tersebut tanpa harus membuat repositori baru.
- Perintah git remote digunakan untuk mengelola repositori Jarak jauh, seperti kita bisa menambahkan, melihat, atau menghapus remote repositori yang berhubung ke repositori local.
- Perintah git add untuk menambhkan perubahan file. jadi kita bisa menambahkan fike tertentu atau semua file yang diubah
- Perintah git commit digunakan untuk menyimpan perubahan yang sudah ditambahkan repositori yang ada. Misalnya git commit -m "Menambahkan Tugas 1"
- Perintah git push digunakan untuk mengirimkan perubahan yang ada di repositori kita dan orang lain bisa mengakses file tesebut
- Perintah git checkout digunakan untuk berpindah antara cabang (branch) di dalam repositori. Jadi, kita bisa melihat atau mengerjakan sesuatu yang berbeda tanpa merusak yang sedang kamu kerjakan sekarang.


4. Jelaskan perbedaan antara GitHub dan GitLab
GitHub lebih cocok untuk proyek open-source yang membutuhkan kolaborasi luas, integrasi dengan banyak alat, dan antarmuka yang sederhana. Sedangkan GitLab lebih cocok untuk tim atau perusahaan yang membutuhkan kontrol lebih pada seluruh siklus hidup pengembangan perangkat lunak, dengan dukungan kuat untuk CI/CD dan self-hosting.


5. Apa bedanya variable user dengan variable system?
Variabel user dapat digunakan untuk menyimpan masukan atau input dari user, seperti nama user, umur, berat badan, dll. Variabel user cakupan ruang lingkupnya ditentukan oleh kia sebagai progremer. Variabel User untuk segi keamanan lebih rentan terhadap serangan yang tidak diinginkan oleh pengguna. Sedangkan variable system selalu dapat diakses, apapun cakupannya seperti <?php // variable system 
echo 'Dokumen Root '.$_SERVER["DOCUMENT_ROOT"]; 
echo '<br/>Nama File '.$_SERVER["PHP_SELF"]; 
?>. Variabel system cakupan lingkupnya global/luas. Variabel system lebih aman karena nilai nilainya ditentukan oleh system operasi atau server web.


6. Apa persamaan variable system dengan variable konstanta ?
Persamaan antara variable system dan variable konstanta adalah Keduanya tidak dapat diubah nilainya setelah didefinisikan, jadi keduanya memiliki nilai yang tetap dan tidak dapat diubah. Keduanya dapat diakses dimana saja dalam skrip php, tanpa perlu memperhatikan ruang lingkup. Keduanya memiliki nilai yang pasti dan tidak dapat berubah secara terduga.
